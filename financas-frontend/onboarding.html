🌡️

Termômetro Financeiro Pessoal

A cada mês (dias 5-10), o sistema calcula um indicador que mede a saúde financeira em duas dimensões:

Comportamental

Você responde 3 perguntas:

  • ✅ Está sobrando dinheiro?
  • ✅ Está usando crédito para fechar?
  • ✅ Renda estável/previsível?

Cada "sim" = 100%, cada "não" = 0%. Média das respostas.

÷

Numérica

Sistema calcula automaticamente:

  • 📊 Superávit ≥ 20% = 100%
  • 📊 Superávit 0-19% = 75%
  • 📊 Déficit até -10% = 40%
  • 📊 Déficit > -10% = 0%
80-100% Estável
60-79% Atenção
40-59% Alerta
0-39% Emergência

⚠️ Estado de Emergência: Se TFP < 40% o sistema ativa automaticamente proteção: bloqueia parcelamentos, redireciona investimentos para liquidez.
