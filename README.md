# 📜 Constituição Financeira Pessoal

Sistema de gestão financeira pessoal baseado em uma metodologia própria chamada **Constituição Financeira Pessoal**.

O projeto organiza a vida financeira por meio de regras constitucionais, gatilhos financeiros, controle de receitas, despesas, cartões, ativos, fluxo de caixa, Termômetro Financeiro Pessoal e Estado de Emergência Financeira.

## 🎯 Objetivo

Transformar uma metodologia pessoal de organização financeira em uma aplicação web funcional, com backend em Java/Spring Boot, banco PostgreSQL e frontend em HTML, CSS e JavaScript.

## 🧠 Conceito

A Constituição Financeira Pessoal funciona como um conjunto de regras financeiras adaptáveis, com:

- Regra base: Recebeu → Separou → Investiu → Depois gastou
- Gatilhos financeiros por nível de gastos
- Reserva Flex
- Controle de cartão de crédito
- Termômetro Financeiro Pessoal
- Estado de Emergência Financeira
- Livro de Ocorrências
- Revisões trimestrais
