# constituicao-financeira-pessoal

## Deploy simples na Oracle Cloud Infrastructure (recomendado para iniciantes)

O primeiro deploy recomendado é usando uma VM Ubuntu na OCI com Docker Compose.
Veja o guia passo-a-passo em `DEPLOY_OCI_VM_SIMPLES.md`.

Observação: O projeto também contém manifests e scripts para Kubernetes/OKE para evolução futura, mas para começar use a opção VM + Docker Compose.
