# 📜 Constituição Financeira Pessoal

Sistema de gestão financeira pessoal baseado em uma metodologia própria chamada **Constituição Financeira Pessoal**.

O projeto tem como objetivo transformar regras financeiras pessoais em uma aplicação web organizada, com controle de usuários, receitas, despesas, cartões de crédito, ativos, fluxo de caixa, termômetro financeiro e estado de emergência financeira.

---

## 🎯 Objetivo do Projeto

A proposta do sistema é ajudar o usuário a organizar sua vida financeira com base em regras claras, revisões periódicas e acompanhamento visual.

A metodologia segue a ideia de uma “constituição” pessoal, onde cada usuário pode ter suas próprias regras financeiras, gatilhos, limites e revisões.
