🚀 COMO COMEÇAR (SUPER SIMPLES)
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Leia a documentação
────────────────────────────
  Arquivo: INSTRUCOES_PRATICAS.md
  Tempo: 5 minutos
  ✅ Você saberá exatamente o que fazer


PASSO 2: Configure o ambiente
──────────────────────────────
  1. Abra: pessoais/.env.example
  2. Copie para: pessoais/.env
  3. Edite com suas credenciais PostgreSQL
  4. Certifique-se PostgreSQL está rodando
  5. Crie banco: CREATE DATABASE financas_pessoais;


PASSO 3: Inicie o Backend
─────────────────────────
  Terminal 1:
    cd pessoais
    ./mvnw spring-boot:run

  ✅ Espere até ver: "Started FinancasPessoaisApplication"
  ✅ Backend rodará em: http://localhost:8080


PASSO 4: Inicie o Frontend
──────────────────────────
  Terminal 2:
    cd financas-frontend
    python -m http.server 8000

  OU:
    npx http-server -p 8000

  ✅ Frontend rodará em: http://localhost:8000


PASSO 5: Acesse no navegador
────────────────────────────
  http://localhost:8000


PASSO 6: Teste o fluxo
──────────────────────
  1. Clique em "Registrar"
  2. Email: teste@example.com
  3. Senha: senha123
  4. Clique "ENTRAR"
  5. Você entrará em perfil.html
  6. Clique "Editar" e adicione seus dados
  7. Configure constituição financeira
  8. Faça uma simulação!

═══════════════════════════════════════════════════════════════════════════════
🆘 PROBLEMAS COMUNS
═══════════════════════════════════════════════════════════════════════════════

Problema: "Connection refused: 5432"
Solução: PostgreSQL não está rodando
  → Inicie o serviço PostgreSQL

Problema: "CORS error" no frontend
Solução: CorsConfig não foi carregado
  → Reinicie o backend após criar CorsConfig.java

Problema: "Token inválido"
Solução: Token expirou ou não foi salvado
  → Faça login novamente

Problema: Dados não aparecem
Solução: Frontend não consegue conectar ao backend
  → Verifique se ambos estão rodando (terminal 1 e 2)
